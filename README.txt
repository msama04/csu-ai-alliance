CSU AI ALLIANCE WEBSITE
=======================

WHAT TO EDIT
------------
Open config.js.

That is where you can easily change:
- Join website URL
- Instagram
- Club email
- President / Treasurer / Advisor names
- Event dates and information

IMPORTANT ABOUT THE QR CODE
---------------------------
The included QR code currently points to:
https://example.com/#join

After you publish the website, replace the joinUrl in config.js with your real URL.

Then regenerate the QR code using any QR generator, or ask ChatGPT:
"Update the QR code in my CSU AI Alliance website to point to [YOUR URL]."

HOW TO PREVIEW
--------------
Double-click index.html to open the site in your browser.

HOW TO PUBLISH
--------------
Easy free options:
1. GitHub Pages
2. Netlify
3. Cloudflare Pages

Once published, your final URL can be placed in config.js and used for the QR code.

FILES
